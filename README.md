### [AI Document Intelligence](https://github.com/CalamoAndret/ai-document-intelligence)

A document workbench for uploading PDF, TXT, and DOCX files, tracking analysis jobs, and reviewing structured results with source evidence.

**Python · FastAPI · React · PostgreSQL · Docker · Gemini API**

- Integrates Gemini for document classification and structured extraction, alongside a deterministic offline mock for demos and tests.
- Processes jobs asynchronously through a PostgreSQL-backed worker with leases, bounded retries, and protection against stale completion.
- Validates typed outputs and checks source evidence for extracted values; the React dashboard supports result inspection and JSON export.
- Includes backend and frontend tests, with GitHub Actions workflows for linting, database checks, builds, and container smoke tests.

[Explore the code and documentation →](https://github.com/CalamoAndret/ai-document-intelligence)
